## 已觀察的影響鏈

兩版全部 XY sensor prior 相同，下一筆 GNSS 預測亦相同。變動來自過去高度 anchor 的更新：最大版本差出現在 **idx723**，v5.16.4 高度1.62862m、v5.16.5高度1.45714m，差 **−0.17148m**。高度會影響後續尺度 seed、點雲公尺幾何及地圖配對。

map 接受次數由 **1753→1614**，少139次。完整輸出的 XY 版本差中位數0.04428m、p95為0.20192m，最大0.40394m（idx916）。這些是輸出差異，不是真實誤差；不能根據它們指定哪一幀導致正式分數變差。

在 v5.16.5 中，相鄰影格都接受高度更新的941組標準化 innovation，其相鄰相關係數為 **0.732**，同號比例約77.8%。這顯示高度殘差具有延續性，可能來自場景、ground plane、配對或模型誤差；不能把這個統計量直接當成已知量測噪聲相關係數，或據此調整 covariance。

## 仍待驗證的原因假說

純資料 H／g 移除了 objective 中明寫的 prior，但配對仍由當幀估計、ground plane 與尺度選出。來源平面的傾斜／距離誤差會同時影響尺度與位置，連續影格也可能反覆看到同一個表面。現有局部 likelihood 和高度 filter 沒有完整描述這些共享誤差，數值驗收全部通過仍可能讓高度 anchor 追隨有偏幾何。

此外，高度 anchor 和位置 correction 都曾吸收過去 map 資料，交叉 covariance 尚未保存。[doc100](100_TRACK2_HEIGHT_POSE_INFORMATION_20261105.md) 的高度條件資訊診斷仍屬研究，不能把高度假裝成獨立量測直接套用。這次先停用失敗分支，後續需從聯合狀態或保守的共享誤差模型研究，而非只提高接受率或降低資訊門檻。
