# 19｜學習目的與算法改進原則

紀錄日期：2026-10-17（Asia/Taipei）。依使用者明確要求記錄，供後續討論、開發與交接遵循。

使用者上這門課的初衷，是學習並增加把自己的知識應用在真實世界的能力。希望透過自己的思考，找出更適合問題的算法；只有必要時，才透過調整參數改善成績。

## 後續如何合作

1. 從實際資料、失敗案例與模型假設找問題，清楚區分觀測、推論及尚未確認的事項。
2. 先解釋候選算法的原理、數學／物理意義、適用前提，以及為何可能改善現有方法，讓使用者能參與推導與選擇。
3. 依已授權範圍完成實作與驗證，保留可比較版本、成功／失敗證據與限制；完整 Track 仍由使用者手動執行。
4. 用消融與測試回答事先提出的假說，檢查方法在不同序列、條件或已知場景的行為。Kaggle 分數是結果證據之一，方法也要能說明其有效原因與適用範圍。

## 參數調整的定位

優先改善模型、觀測方式、誤差處理及算法結構。非必要不以特定 Track／幀區間的客製權重、排行榜回饋的反覆微調，或大量盲目搜尋參數為主要改進途徑。

參數調整仍可用於必要的感測器噪聲設定、實測標定、模型適用範圍及數值穩定性。進行前須說清楚「哪個假設需要校正、參數代表什麼、依據是什麼、如何驗證」；實驗後分開記錄算法變更與參數變更的效果。不同 Track 使用不同設定時，需有資料／標定依據，單次較低分數不足以證明一般有效性。

後續工作的成果應包含使用者能解釋的推理、可重現的實作，以及實測結果與限制。此原則延續既有授權與手動完整測試約定，不額外要求每次修復或驗證先停下確認。
